Como dominar a IA em segundos

A Arte de Pedir

"A IA é como um estagiário brilhante, mas que não conhece o seu negócio. Se você pedir 'uma descrição', ele fará o básico. Se você pedir 'uma descrição persuasiva, focada em famílias, destacando a sacada gourmet', você terá um resultado profissional."

A Fórmula Mestra: C.R.I.A.

C - Contexto: Quem a IA deve ser? (Corretor, Redator...)
R - Regra: Qual a tarefa exata?
I - Informação: Quais os dados brutos?
A - Ajuste: Qual o tom? (Entusiasmado, formal...)

Como utilizar os prompts:

  1. 1. Escolha: Navegue pelas categorias ou use a busca para achar o prompt ideal.
  2. 2. Copie: Clique no botão "Copiar" abaixo do prompt escolhido.
  3. 3. Cole & Edite: Cole no seu Gemini/ChatGPT e preencha os dados entre colchetes [COMO ESTE].
  4. 4. Ajuste: Se precisar, peça para a IA: "deixe mais curto" ou "mude o tom".
