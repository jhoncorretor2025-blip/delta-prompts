🧑‍💻 Codex do ChatGPT

Prompts para usar o Codex, o agente de programação do ChatGPT: criar, corrigir, revisar e documentar código com a ajuda da IA.

🧠 O que é o Codex?

O Codex é o agente de programação da OpenAI, disponível dentro dos planos do ChatGPT (inclusive no gratuito, com limites menores). Ele consegue escrever código, corrigir bugs, revisar mudanças, responder perguntas sobre um projeto inteiro e até propor alterações prontas — tudo a partir de um pedido em português simples.

🗺️ Como os prompts estão organizados

  • 🚀 Primeiros Passos: entender um projeto que você não conhece.
  • 🐛 Correção & Manutenção: corrigir bugs e refatorar código antigo.
  • ✨ Criação: novas funcionalidades e projetos do zero.
  • 🔍 Revisão & Qualidade: revisar pull requests, testes e segurança.
  • 📄 Documentação: documentar código automaticamente.
  • 🔄 Automação: scripts para tarefas repetitivas.
