Você não precisa entender de programação nem saber o nome do prompt. Basta escolher o problema. O Delta mostra o prompt certo.

1️⃣ Escolha
O problema que você está vendo.
2️⃣ Veja

3️⃣ Copie
Clique em “Copiar este prompt”.
4️⃣ Cole na IA
Envie o link, código/arquivos ou prints.
💡 Exemplo: “Meu site está feio” → clique em Melhorar o visual → copie o prompt → abra sua IA → cole o prompt → envie o link ou os arquivos do site.
